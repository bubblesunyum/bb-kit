Two things want the owner's eye before FilterBar, neither blocking:

- **bbk-box** (filed this session) — Badge's default is Button's 40px, per plan

  Storybook first.

The thing I was mid-thought on: whether the `rounded-full` problem I hit on
Badge (now bd remember `rounded-full-clips-a-wrapped-pill`) is lurking anywhere
else. Nothing else in the kit uses `rounded-full` today, so there is nothing to
fix — but SearchField is the next pill-ish thing and it will be tempting, and
Skeleton's rounded ends are worth a glance if a skeleton ever gets tall.

One rejected approach worth naming, because it still tempts: I considered
keeping `rounded-full` and just adding more horizontal padding. That only moves
the collision — the curve inset scales with height, padding does not, so a tag
one line longer breaks it again. Half-the-minimum-height is the version that
cannot come back.

Also: the taste reviewer flagged `hover:bg-muted` as needing to be
`bg-muted-surface`. It is wrong — the token is `--color-muted` — and a future
session will likely get the same finding, since the plan's §5.1 table calls the
role "Muted surface" while the CSS calls it `muted`. Not worth changing the
token; worth recognising the finding on sight.
